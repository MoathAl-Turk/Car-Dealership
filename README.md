# Car Dealership Portfolio Showcase 🚗

**[View the Portfolio Here!](https://moathal-turk.github.io/Car-Dealership/)**

## Overview
A static web portfolio designed to document and showcase of this project. Rather than a functional web application, this site serves as a visual gallery and informational hub, featuring images and detailed write-ups that explain the physical project's layout, design, and execution.

## Tech Stack
* **Frontend:** HTML, CSS, JavaScript
* **Deployment:** GitHub Pages

## How to View
1. Visit the [live portfolio site](https://moathal-turk.github.io/Car-Dealership/).
2. Browse through the image galleries and read the descriptions to learn more about the physical dealership project.

## Local Setup (For Developers)
If you want to view the code or use this layout as a template:
1. Clone the repository: `git clone https://github.com/MoathAl-Turk/Car-Dealership.git`
2. Open `index.html` in your web browser to view the site locally.
